Pilote USB CH9102 / CH343 (WCH)
================================

Placez ici le pilote officiel WCH avant de packager l'application :

    CH343SER.EXE

Téléchargement officiel :
    https://www.wch-ic.com/downloads/CH343SER_ZIP.html
    (décompressez le ZIP et copiez CH343SER.EXE dans ce dossier)

Ce dossier est embarqué dans l'application portable (ToodoohFlasher.exe) et se
retrouve à côté de l'exécutable une fois lancé, dans  resources/drivers/.

L'utilisateur installe le pilote une seule fois par ordinateur (voir
docs/GUIDE-PREMIERE-UTILISATION.md).
